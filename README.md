## Текущий статус

Владелец сообщил, что его DGX Spark — NVIDIA GB10 с 128 ГБ unified memory, Ubuntu 24.04.5 LTS ARM64 и примерно 3,5 ТБ свободного места. `nvidia-smi` не показывает объём GPU memory (`N/A`); 128-ГБ конфигурация следует из вывода `MemTotal` и `free -h`. Docker daemon активен, но обычный пользователь не имеет доступа к socket; `sudo docker info` возвращает версию 29.6.2.

**Эти данные переданы владельцем, не получены агентом напрямую.** По решению владельца модели пока не скачивались и не запускались; Qwen API, ComfyUI и генерация изображения на Spark не проверены. Аппаратная приёмка остаётся **pending**. Не считайте синтаксическую проверку скрипта или доступность Docker подтверждением установки.

## Область проекта

- Документы разделяют 64- и 128-ГБ рецепты; для указанного устройства основной кандидат — 128-ГБ ветка. 64-ГБ вариант остаётся отдельной справочной конфигурацией.
- DGX Spark предоставляет inference API и, опционально, image-generation runtime; Windows остаётся машиной разработки и сборки приложений.
- Начальные кандидаты (модели не установлены): Qwen3.8-27B NVFP4 для coding API и ComfyUI + Z-Image BF16 для генерации изображений; последовательность и оговорки — в [плане установки](./docs/model-install-plan.md).
- FLUX.2 Klein, embeddings/reranker и OCR — опционально позже, до подтверждения точного runtime и end-to-end процедуры; лицензии и статусы приведены в [матрице](./docs/model-and-license-matrix.md).
- Любой компонент включается только при наличии источника, точного идентификатора, понятной лицензии и применимого runtime.
- Публичная лицензия самого репозитория **не выбрана**. Не считать отсутствие файла `LICENSE` разрешением на повторное использование.

## Статусы доказательств

В документах различаются четыре вида подтверждения:

1. **Сообщено владельцем** — вывод или факт предоставлен владельцем, но не проверен агентом.
2. **Сверено с источником** — описание сопоставлено с указанным первичным источником или рецептом.
3. **Статически проверено** — например, shell-файл прошёл `bash -n`; это не проверка запуска.
4. **Проверено на устройстве** — команда реально выполнена на указанной конфигурации, результат зафиксирован.

Пока последний статус не получен для Qwen и ComfyUI, проект не заявляет, что эти модели установлены или работают на DGX Spark владельца.

## Безопасность

- Не добавляйте пользователя в группу `docker` без отдельного решения: доступ к Docker daemon даёт привилегии уровня root.
- Держите inference API на loopback и подключайтесь через SSH-туннель; не публикуйте неаутентифицированный сервис в сети.
- Перед установкой сверяйте свободное место, точный checkpoint и лицензию; не коммитьте токены, пользовательские логи или машинные идентификаторы.
